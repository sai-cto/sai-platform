# BRSS: rules ported from the Salesforce system

Every business rule in this module that came from the old Salesforce org, with where it lives
here and where it was found there. 84 rules.

- **"In this module"** paths are inside `src/modules/brss/`.
- **"Salesforce source"** paths are inside the read-only reference repository
  `sai-cto/brss-salesforce` (commit `233cf40`), as `file:line`. The rule ids (`R-ORD-…`,
  `R-SCH-…`) are the ones used in `docs/brss-analysis/`, which describes each rule in full.
- Most rules are plain functions in `rules.ts`, each with a test in
  `tests/integration/brss.test.ts`.

Rules that were **not** ported, and behaviour that was deliberately **not copied**, are listed
in `README.md` in this folder. Things the old code leaves unclear are in `OPEN_QUESTIONS.md`.
