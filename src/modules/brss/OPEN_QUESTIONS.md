# BRSS: open questions

Things the Salesforce code leaves unclear, contradicts itself on, or keeps in data that is
not in the reference repository. Nothing here was guessed silently: where the module had to
choose in order to work at all, the choice is in `README.md` ("Decisions waiting for the
CTO"), and everything else is simply not built.

These are for a BRSS manager to answer. Each has the place in the old system it comes from
(`sai-cto/brss-salesforce`, commit `233cf40`); the full discussion is in `docs/brss-analysis/`.
